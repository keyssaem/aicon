# 배포 안내 (P1)

화면과 게임 서버를 **한 주소에서** 제공합니다. `apps/server`가 `/`로 화면을, `/cards/`로 카드 이미지를,
`/socket.io/`로 게임 연결을 맡습니다. 그래서 CORS 설정이 필요 없고 배포도 한 번에 끝납니다.

## 1. 로컬에서 확인

```bash
npm install
npm run build          # 화면 빌드 + 정답 유출 검사
npm start              # http://localhost:5175 에서 화면까지 함께 제공
```

개발 중에는 두 개를 따로 띄웁니다.

```bash
npm run dev:server     # 게임 서버 (5175)
npm run dev:web        # 화면 (5174, /socket.io 요청은 5175로 넘어갑니다)
```

## 2. 환경 변수

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 5175 | 서버 포트 (대부분의 호스팅은 이 값을 자동으로 넣어 줍니다) |
| `HOST` | 0.0.0.0 | 바인딩 주소 |
| `AICON_WEB_DIST` | `apps/web/dist` | 화면 빌드 폴더 |
| `AICON_CARDS_DIR` | `packages/content/assets/cards` | 카드 이미지 폴더 |
| `AICON_CORS_ORIGIN` | `*` | 화면을 다른 주소에서 띄울 때만 사용 |
| `LOG_LEVEL` | info | 로그 수준 |

## 3. 어디에 올릴까

교실에서 쓰려면 **항상 켜져 있는 작은 서버 하나**면 충분합니다. 일정 시간 요청이 없으면 잠드는 무료 요금제는
수업 시작 때 첫 입장이 수십 초 걸려서 권하지 않습니다.

| 방법 | 장점 | 확인할 점 |
| --- | --- | --- |
| **Fly.io (도쿄 리전)** | `fly launch`로 Dockerfile 그대로 배포, HTTPS·도메인 연결 자동 | 카드 결제 등록 필요 |
| **AWS Lightsail (서울 리전)** | 국내에서 가장 빠름, 고정 요금 | 서버 관리(업데이트·재시작)를 직접 |
| **Render / Railway** | 깃 연동 후 자동 배포 | 잠들지 않는 유료 요금제를 고를 것 |
| **교내·개인 서버 + Cloudflare Tunnel** | 추가 비용 없음 | 학교망 정책 확인 필요 |

Docker 이미지는 이미 준비되어 있습니다.

```bash
docker build -t aicon .
docker run -p 8080:8080 aicon      # http://localhost:8080
```

## 4. 도메인과 HTTPS

1. 도메인을 정합니다. 새로 사는 경우 `aicon.kr` 같은 짧은 주소가 학생이 입력하기 좋습니다.
   이미 쓰는 도메인이 있다면 `aicon.<기존도메인>` 서브도메인이 가장 간단합니다.
2. 호스팅이 준 주소로 DNS를 연결합니다 (A 레코드 또는 CNAME).
3. HTTPS 인증서는 위 호스팅들이 자동으로 발급합니다. **반드시 https로 접속**해야 합니다.
   http로 열면 일부 브라우저가 소켓 연결을 막습니다.

## 5. 학교에서 쓰기 전 점검표

- [ ] 학교 와이파이에서 태블릿 4대로 실제 한 판을 진행해 봅니다.
- [ ] 웹소켓이 막힌 망에서도 접속되는지 확인합니다. (막히면 자동으로 롱폴링으로 이어집니다)
- [ ] 교육청 유해사이트 차단 목록에 걸리지 않는지 확인합니다.
- [ ] 수업 중에는 배포하지 않습니다. 서버를 다시 시작하면 **진행 중이던 방이 사라집니다.**
      (방 상태를 저장하는 기능은 P3 과제입니다.)
- [ ] `/healthz`로 서버 상태와 현재 방 수를 확인할 수 있습니다.

## 6. 운영 중 알아 둘 것

- 방은 **30분 동안 아무 일도 없으면 자동으로 닫힙니다.**
- 같은 자리로 다른 기기가 들어오면 먼저 있던 연결은 끊깁니다. (한 자리에 한 명)
- 접속이 끊긴 사람의 차례는 45초 뒤 자동으로 넘어갑니다. 돌아오면 원래 자리에서 이어서 합니다.
- 방 코드는 6자리 숫자이며, 한 소켓이 1분에 20번 넘게 입장을 시도하면 잠시 막습니다.
